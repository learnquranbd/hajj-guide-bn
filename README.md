# 🕋 হজ গাইড — Hajj Guide (Bangla)

হজ্জে তামাত্তুর পূর্ণাঙ্গ বাংলা নির্দেশিকা — ধাপে ধাপে করণীয়, ফরজ-ওয়াজিব-সুন্নত,
শব্দে শব্দে অর্থসহ মাসনূন দোয়া ও নামাজ, এবং মিনা-আরাফাত-মুজদালিফার ইন্টারঅ্যাক্টিভ মানচিত্র।

A complete Bangla guide to **Hajj at-Tamattu** — static HTML, no build step, hosted on Firebase.

## বৈশিষ্ট্য / Features

- 🕋 **কিসওয়া থিম** — কাবার গিলাফের কালো সিল্ক ও সোনালি জরি; বিকল্প পার্চমেন্ট (হালকা) থিম টগল করে নেওয়া যায়
- 📱 সম্পূর্ণ রেসপনসিভ — ৪০০px পর্যন্ত কোনো হরাইজন্টাল স্ক্রল নেই
- 💾 অগ্রগতি সংরক্ষণ — `localStorage`-এ, ইন্টারনেট ছাড়াই
- 🆘 হেডারে সহায়তা মেনু — অ্যাপ, সৌদি জরুরি নম্বর ও বাংলাদেশ হজ মিশনের যোগাযোগ
- 🪪 হোমে নিবন্ধন অনুসন্ধান — নম্বর কপি করে hajj.gov.bd-তে পাঠায় (কোনো তথ্য সংরক্ষণ বা প্রেরণ করে না)
- 🔍 `/faq` ও `/terms`-এ তাৎক্ষণিক অনুসন্ধান — সার্ভার ছাড়াই, ব্রাউজারেই
- 🖼️ শেয়ার প্রিভিউ — সব পেজে Open Graph ও Twitter Card, `img/og-cover.jpg`
- 🗺️ `sitemap.xml` ও `robots.txt`
- 🔢 সব সংখ্যা বাংলা অঙ্কে
- 🚫 কোনো বিল্ড স্টেপ নেই, কোনো npm ডিপেন্ডেন্সি নেই — শুধু ES modules

## লোকাল রান / Run locally

```bash
firebase serve --only hosting --port 5099
# → http://localhost:5099
```

## ডিপ্লয় / Deploy

```bash
firebase deploy --only hosting
```

## ক্লাউড সিঙ্ক চালু করা (ঐচ্ছিক)

ডিফল্টে অগ্রগতি শুধু ব্রাউজারে থাকে। একাধিক ডিভাইসে সিঙ্ক করতে চাইলে:

1. Firebase Console → **Build → Firestore Database → Create database**
2. **Build → Authentication → Sign-in method → Anonymous → Enable**
3. `public/js/firebase-config.js`-এ `CLOUD_SYNC = true` করুন
4. `firebase deploy`

`firestore.rules` ইতিমধ্যে লেখা আছে — প্রতিটি ব্যবহারকারী কেবল নিজের ডকুমেন্ট পড়তে ও লিখতে পারবেন।
সিঙ্ক ব্যর্থ হলে অ্যাপ নিঃশব্দে localStorage-এ চলতে থাকে, কোনো পেজ ভাঙে না।

## কনটেন্ট সম্পর্কে / About the content

তথ্যগুলো কুরআন, সহীহ হাদীস (বুখারী, মুসলিম, তিরমিযী, আবূ দাউদ) ও প্রচলিত ফিকহি গ্রন্থের
ভিত্তিতে সংকলিত; মাযহাবি বিধান মূলত **হানাফি** মত অনুসারে, যেখানে মতভেদ আছে সেখানে তা উল্লেখ করা হয়েছে।
প্রতিটি দোয়ার সাথে সূত্র দেওয়া আছে।

> **কসর নিয়ে বিশেষ নোট:** মিনা-আরাফাতে হাজী চার রাকাত পড়বেন না দুই — এ নিয়ে মাযহাবি পার্থক্য আছে।
> হানাফি মতে মক্কায় ১৫+ দিন থাকার নিয়তকারী হাজী মুকীম, তাই তিনি মিনা-আরাফাতেও পূর্ণ চার রাকাত পড়বেন;
> বাকি তিন মাযহাবে সব হাজীই কসর করেন। `/salat` ও `/rules#salat`-এ দুটি মতই উল্লেখ করা আছে।

**এটি শিক্ষামূলক উদ্দেশ্যে তৈরি।** মাসআলা-সংক্রান্ত চূড়ান্ত সিদ্ধান্তের জন্য নির্ভরযোগ্য আলেম বা
হজ গাইডের পরামর্শ নিন। মানচিত্রগুলো বোঝার সুবিধার্থে আঁকা পরিকল্পনামূলক স্কেচ — GPS-নির্ভুল নয়;
মাঠে চলার জন্য **Nusuk** অ্যাপ ও মুয়াল্লিমের নির্দেশনা অনুসরণ করুন।

## ম্যাপ সম্পর্কে

গুগল কী ছাড়া Google Maps আর iframe-এ বসানো যায় না (`x-frame-options: SAMEORIGIN`)।
তাই `/map`-এর স্যাটেলাইট ম্যাপটি **Leaflet + Esri World Imagery** দিয়ে আঁকা, রাস্তার লেয়ার
**OpenStreetMap**; আর গুগল ম্যাপ খোলে বোতামে — ফোনে সরাসরি গুগল ম্যাপ অ্যাপে চলে যায়।

পৃষ্ঠার ভেতরেই গুগলের ম্যাপ দেখাতে চাইলে `public/map.html`-এ
`const GMAPS_KEY = ''` লাইনে নিজের **Google Maps Embed API** কী বসিয়ে দিন
(কী-টি HTTP referrer দিয়ে সীমাবদ্ধ করে নিন)।

## অফলাইনে পড়ার ব্যবস্থা (এখনো বন্ধ)

মিনা, আরাফাত ও মুজদালিফায় নেটওয়ার্ক প্রায়ই থাকে না — তাই `public/sw.js`-এ একটি
সার্ভিস ওয়ার্কার লেখা আছে: পেজে আগে নেটওয়ার্ক, না পেলে ক্যাশ, তাও না পেলে `/offline`।
সাথে `manifest.webmanifest` ও আইকন আছে, তাই সাইটটি ফোনে "ইনস্টল" করা যায়।

**তবে এটি এখনো চালু করা হয়নি** — আসল ব্রাউজারে পরীক্ষা করা যায়নি, আর ভুল সার্ভিস
ওয়ার্কার একবার বসে গেলে ব্যবহারকারীর ব্রাউজারে আটকে থাকে। চালু করতে:

1. `public/js/firebase-config.js`-এ `OFFLINE_MODE = true` করুন
2. একটি ফোনে খুলে কয়েকটি পেজ ঘুরে দেখুন
3. ফ্লাইট মোড চালু করে দেখুন পেজগুলো এখনো খোলে কিনা
4. ঠিক থাকলে `./bump-version.sh <N> && firebase deploy`

`bump-version.sh` সার্ভিস ওয়ার্কারের ক্যাশ-নামও (`hajj-guide-vN`) একই সংস্করণে
হালনাগাদ করে, তাই পুরোনো ফাইল আটকে থাকে না।

## শব্দে শব্দে অর্থের নীতি

সাইটের একটি কঠোর নিয়ম: **প্রতিটি আরবি উদ্ধৃতির শব্দে শব্দে বাংলা অর্থ থাকতেই হবে** —
দোয়া, সূরা, আয়াত, হাদীস, এমনকি পেজে হাতে বসানো উদ্ধৃতিও। নতুন কিছু যোগ করলে
`w: [['আরবি','অর্থ'], …]` ফিল্ডটি পূরণ করুন, আরবি শব্দ মূল বাক্যের ডান-থেকে-বাম ক্রমে।

যাচাই করতে — `w` জোড়া দিলে মূল `ar` ফিরে আসে কিনা দেখুন:

```bash
node -e "import('./public/js/data-dua.js').then(m=>{
  const norm=t=>t.replace(/[\u064B-\u0652\u0670]/g,'').replace(/[،؛\.]/g,'').replace(/\s+/g,' ').trim();
```
