# 🕋 হজ গাইড — Hajj Guide (Bangla)

হজ্জে তামাত্তুর পূর্ণাঙ্গ বাংলা নির্দেশিকা — ধাপে ধাপে করণীয়, ফরজ-ওয়াজিব-সুন্নত,
শব্দে শব্দে অর্থসহ মাসনূন দোয়া এবং মিনা-আরাফাত-মুজদালিফার ইন্টারঅ্যাক্টিভ মানচিত্র।

A complete Bangla guide to **Hajj at-Tamattu** — static HTML, no build step, hosted on Firebase.

---

| `/steps` | **৩ পর্বে ১৭টি ধাপ** — ইহরাম থেকে বিদায়ী তাওয়াফ, প্রগ্রেস ট্র্যাকিংসহ |
| `/rules` | ফরজ ৩টি, ওয়াজিব ৮টি, সুন্নত, ইহরামের নিষিদ্ধ কাজ, **দম ও সদকার সারণি**, নারীদের মাসআলা |

| `/tips` | প্রস্তুতি, ব্যাগ লিস্ট, স্বাস্থ্য ও হিটস্ট্রোক, হারিয়ে গেলে করণীয়, আত্মিক প্রস্তুতি |

## বৈশিষ্ট্য / Features

- 🌗 লাইট ও ডার্ক থিম — সিস্টেম সেটিং অনুসরণ করে, ম্যানুয়াল টগলও আছে
- 📱 সম্পূর্ণ রেসপনসিভ — ৪০০px পর্যন্ত কোনো হরাইজন্টাল স্ক্রল নেই
- 💾 অগ্রগতি সংরক্ষণ — `localStorage`-এ, ইন্টারনেট ছাড়াই
- 🔢 সব সংখ্যা বাংলা অঙ্কে
- 🚫 কোনো বিল্ড স্টেপ নেই, কোনো npm ডিপেন্ডেন্সি নেই — শুধু ES modules

## প্রযুক্তি / Stack

Vanilla HTML + CSS + ES modules · Firebase Hosting · Firebase Analytics ·
(ঐচ্ছিক) Firestore + Anonymous Auth · ফন্ট: Hind Siliguri, Amiri

```
public/
├── index.html steps.html rules.html dua.html map.html tips.html checklist.html 404.html
├── css/style.css              # ডিজাইন সিস্টেম — টোকেন, থিম, কম্পোনেন্ট
└── js/
    ├── shell.js               # হেডার, নেভ, ফুটার, থিম টগল
    ├── store.js               # অগ্রগতি — localStorage + ঐচ্ছিক Firestore সিঙ্ক
    ├── firebase-config.js      # Firebase কনফিগ + CLOUD_SYNC ফ্ল্যাগ
    ├── data-steps.js          # ১৭টি ধাপ, ৩ পর্বে
    ├── data-dua.js            # ১৯টি দোয়া, শব্দে শব্দে
    └── data-checklist.js      # ৪৩টি চেকলিস্ট আইটেম
```

কনটেন্ট সবই ডেটা ফাইলে — পেজগুলো সেখান থেকে রেন্ডার করে। নতুন দোয়া বা ধাপ যোগ করতে
শুধু সংশ্লিষ্ট `data-*.js` ফাইলে একটি অবজেক্ট যোগ করুন, HTML ছুঁতে হবে না।

## লোকাল রান / Run locally

```bash
firebase serve --only hosting --port 5099
# → http://localhost:5099
```

> ES modules ব্যবহার করায় `file://` দিয়ে খোলা যাবে না, একটি সার্ভার লাগবেই।

## ডিপ্লয় / Deploy

```bash
firebase deploy --only hosting
```

## ক্লাউড সিঙ্ক চালু করা (ঐচ্ছিক)

ডিফল্টে অগ্রগতি শুধু ব্রাউজারে থাকে। একাধিক ডিভাইসে সিঙ্ক করতে চাইলে:

1. Firebase Console → **Build → Firestore Database → Create database**
2. **Build → Authentication → Sign-in method → Anonymous → Enable**
3. `public/js/firebase-config.js`-এ `CLOUD_SYNC = true` করুন
4. `firebase deploy`

`firestore.rules` ইতিমধ্যে লেখা আছে — প্রতিটি ব্যবহারকারী কেবল নিজের ডকুমেন্ট পড়তে ও লিখতে পারবেন।
সিঙ্ক ব্যর্থ হলে অ্যাপ নিঃশব্দে localStorage-এ চলতে থাকে, কোনো পেজ ভাঙে না।

## কনটেন্ট সম্পর্কে / About the content

তথ্যগুলো কুরআন, সহীহ হাদীস (বুখারী, মুসলিম, তিরমিযী, আবূ দাউদ) ও প্রচলিত ফিকহি গ্রন্থের
ভিত্তিতে সংকলিত; মাযহাবি বিধান মূলত **হানাফি** মত অনুসারে, যেখানে মতভেদ আছে সেখানে তা উল্লেখ করা হয়েছে।
প্রতিটি দোয়ার সাথে সূত্র দেওয়া আছে।

**এটি শিক্ষামূলক উদ্দেশ্যে তৈরি।** মাসআলা-সংক্রান্ত চূড়ান্ত সিদ্ধান্তের জন্য নির্ভরযোগ্য আলেম বা
হজ গাইডের পরামর্শ নিন। মানচিত্রগুলো বোঝার সুবিধার্থে আঁকা পরিকল্পনামূলক স্কেচ — GPS-নির্ভুল নয়;
মাঠে চলার জন্য **Nusuk** অ্যাপ ও মুয়াল্লিমের নির্দেশনা অনুসরণ করুন।
